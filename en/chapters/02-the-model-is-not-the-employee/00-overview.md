# Chapter 2: The Model Is Not the Employee

With the picture complete, we can use it to walk through an agent's life from the beginning.

The beginning is not the agent itself — it starts before the agent is born. That is what this chapter covers: what a model-training company delivers is not an agent but a candidate. Pretraining is general education, post-training is vocational education, and model tiers are a diploma. A degree tells you how capable the candidate is. It does not tell you which job the candidate is right for.

Treating the model directly as an employee is the earliest and easiest mistake to make. It confuses two different things: a person having ability, and a person getting work done in a role.
