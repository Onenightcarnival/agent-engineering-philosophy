# 超级个体的回归

接着科斯的边界往下推。AI 把内部协调成本压向零，交点会移到哪里？

一直移到个体。

## 协调成本趋零，边界收缩到一个人

一个人过去要完成一件稍大的事，得协调一个团队——招人、分工、开会、对齐、监督。这些都是内部协调成本，正是它撑起了公司的体量：事情大到一个人协调不过来，就需要组织。

现在，这个人可以靠调度一组随时 fan-out、用完即融的 agent 算力来完成同样的事。要并行，就分出一批子 agent；干完，结果收回来。协调它们的成本，比协调一个人类团队低几个数量级。按科斯的逻辑，内部协调成本趋零，企业边界就收缩——一直收缩到个体。

所以超级个体不是一句个人英雄主义的口号，是协调成本结构变化后的必然产物。一个清醒、担责的人，加上一组流动的 agent 能力，可以顶过去需要一整张组织架构图才能做的事。组织的最小可行单位，正在变小。

## 一个绕不过去的追问

但这里立刻冒出一个追问，得留到后面才能答全。

既然能力可以靠 agent 补齐，协调成本又趋零，那为什么这个中心还非得是"一个人"不可？为什么不能连这个人也省掉，让一组 agent 自己运转成一个无人的组织？
