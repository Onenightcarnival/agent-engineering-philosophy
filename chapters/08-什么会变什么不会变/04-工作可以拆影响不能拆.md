# 工作可以拆，影响不能拆

上一篇留下的另一条轴，是责任。它和能力、真相走的方向相反。

工作可以拆。一件事 fan-out 成一堆子任务，并行，分给一群 agent，干完再合起来——这正是 agent 的长处。但影响不能拆。一个 agent 团队造成的后果——犯的错、欠的责、对外许下的承诺——不会因为工作被拆成十份，就也分成十份摊薄。后果是一个整体，落在一处。

## 这是律令，不是现状

要紧的是看清这句话的身份：它是一条法则，一条"应当如此"的律令，不是对现状的描述。

现状恰恰相反。今天一个 agent 出了事，责任是弥散的——散在模型提供商、写 prompt 的人、提供工具的一方、下指令的用户之间，比人类组织还要糊。没有人是那个唯一的源头，每一方都能指向另一方。所以"影响不能拆"此刻并不成立，它是要争取的状态，不是已经在手的状态。

更麻烦的是，AI 主动诱惑你违反它。既然工作能 fan-out，就很容易顺势假设影响也 fan-out 了——把责任也一并打散，谁都担一点，等于谁都不真担。这个诱惑很顺手，也很危险。

## 把影响收敛到单一担责点

所以好的 agentic 组织设计，核心动作之一就是抵抗这个诱惑：把影响死死收敛到单一的担责点。

工作尽管拆、尽管并行，但无论拆成多少份，必须有一个唯一的地方，对全部后果负责。这条轴上的收敛，不是顺势发生的趋势，是逆着 AI 默认的扩散、要人为施加的律令。

于是两条轴上的方向凑齐了：可分的——能力、真相、工作——顺势归一；不可分的——责任——逆势守住归一。一句是趋势，一句是律令，方向同样指向"一"，但一个是顺水，一个是逆水人为划定。一个找不到唯一担责点的 agent 系统，无论跑得多漂亮，都是危险的。
