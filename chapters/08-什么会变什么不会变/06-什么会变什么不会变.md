# 什么会变，什么不会变

收束全书。把前面的判断合起来，回到这一章开头那个问题：当传统组织变成 agentic 组织，什么会变，什么不会变。

## 会变的

会变的那一半，谁都看得见。

组织形态会变：企业边界从一个庞大的团队，收缩到一个超级个体加一片流动的 agent 算力。分工方式会变：人类那种不可逆的专业化，被 agent 可逆的临时隔离取代——切开只为干活，干完即融回。能力获得方式会变：不再靠招人、培养、熬资历，而靠挂上一项可验证、可迁移的 skill。协作成本会变：内部协调被压向地板。

这些都是真的变化，值得去做。但它们是"变"，喊出来不需要判断力。

## 不会变的

见判断力的是另一半。

协调仍有根本约束。科斯的逻辑本身没变，变的只是参数：内部协调成本低了，边界移了，但"组织停在内部协调与市场交易成本相等处"这条道理没有变。

判断仍然需要一个主体。可分的能力归了一，不可分的判断与责任没有跟着归一。事实判断要交给最接近真实的人或 agent，最终责任仍然落在一个能担责的人身上——AI 接管了能力，接不了后果。可分与不可分之间那条线，仍然在那里。越过它，假装责任也能 fan-out，是这个时代最顺手、也最危险的错误。

## 全书的落点

这正呼应第一本终章的母题：范式转换里，要紧的从来不是清点什么变了，而是分清什么被重新定义、什么不变。

变的是组织的形态，不变的是约束、判断和责任。

责任底下还压着一层，是德。前面讲过 agent 的迎合倾向：它被训得讨提问者欢心，而不是坚持说对的。这件事提醒我们，agent 的品性不是末端设计出来的。它先从数据里照出人的样子，再被奖励信号定型。善恶都在人类的记录里，它学成什么样，看我们喂什么、奖励什么。

所以德和责任一样，是上游的事，不可外包。末端加一道护栏补不进来，根在训练的源头，在我们把求真摆在讨喜前面还是后面。更关键的是，就算它学得再像，也不为自己的品性负责。它照出我们的样子，却扛不起那个样子的后果。这是责任必须落在人身上的最深一层原因。

agent 让能力、真相、工作大幅归一，这是顺势而为，值得做透。但责任不会跟着归一。它需要一个清醒的人守在中心，尊重事实判断，又守住最终后果，逆着 AI 默认的扩散把它收住。

把可分的归一，把不可分的守住，是 agentic 组织工程最要紧的分寸。这本书从"agent 到底是什么"出发，走过它的一生与它的组织，最后落在这一句上。
