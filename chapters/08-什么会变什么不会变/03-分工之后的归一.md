# 分工之后的归一

人类文明靠分工扩张。能力越分越细，一个人一辈子只精一行，社会靠把这些细分的能力拼起来运转。这个过程是单向的，也是不可逆的——一个人成了律师、另一个成了医生，就合不回去了。

AI 是一股反方向的力：归一，收敛。要看清它，得先分清 agent 的"分工"和人的分工差在哪里。

## agent 的分工更容易回收

agent 团队 fan-out 出一堆子 agent，看起来也是分工。但很多时候，那只是临时的上下文隔离——分出去，是为了不让彼此的上下文互相污染；干完，结果收回来。它们背后的权重可以相同，岗位也可以临时生成，没有谁真的"变成"了一个不可逆的专才。

这就是"归一"在这里的意思：人的分工高度不可逆，agent 的分工更容易回收。人被迫把能力、知识、视角切开，分散到不同的人身上，再也合不拢；agent 的能力、工具和上下文，至少有一部分可以临时切开，再被收回到一个胜任节点。能力、真相、上下文，在 AI 这里有重新收敛的趋势——分工时代被切碎的东西，有机会部分合一。

## 但收敛不是均匀的

这里必须补一句，否则就滑成了一套收敛乌托邦。

收敛不是在所有轴上同样发生。能力和真相这条轴上，AI 确实在收敛——权重可以共享，岗位可以临时化，很多工作可以归到一个胜任节点、一个真相源。这是顺势的趋势，不用费力推动。

但还有一条轴——责任——根本不在收敛，当下甚至在恶化扩散。下一篇专讲它。

所以"归一"有边界。它只对可分的东西成立：能力、真相、工作。把它套到所有事情上，对什么都喊收敛，就会把一个清楚的判断用成口号。

就可分的那部分而言，启示是实在的：不必再默认"复杂的事就该拆给一堆各自为政的专业角色"。AI 让"可分的尽量归一"成为可能——一个真相源、一个胜任节点，胜过一堆互相打架的分身。能单则不双，这是它在系统设计上的样子。
