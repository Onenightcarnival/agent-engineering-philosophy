# 第六章：试用期、晋升与退休

前半生讲完了——出生、入职、上岗、安家。这一章进入 agent 在岗之后的时间：怎么验、怎么长、怎么挪、怎么退。

eval 是试用期，考的是岗位胜任，不是模型排行榜上的名次。绩效要建立在工作记录上，不是建立在印象上。成长大多不发生在权重里。转岗和晋升时，有些东西能跟着走，有些不能无损搬家。而一个 agent 下线，不是 kill 掉进程就完了，是一次有流程的离职。
