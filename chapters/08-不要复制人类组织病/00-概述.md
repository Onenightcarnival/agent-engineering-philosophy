# 第八章：不要复制人类组织病

最后回到一个更贴近 agent 工程的问题：一群 agent 一起工作时，哪些人类组织经验可以学，哪些不能碰。

人力资源是这本书的主干隐喻，但不能整套照搬。人类组织里有些机制来自分工本身：岗位、交接、授权、升级路径。这些要保留。也有些机制来自人性失败：抢功、甩锅、表演、层级压制事实。这些不能复制。agent 还会长出自己的新病：迎合、互相背书、上下文污染、把流畅当正确。这些要另设机制。

多 agent 工程不做公司仿真，它要重新设计一种团队。这一章就收束在这条判断上。
