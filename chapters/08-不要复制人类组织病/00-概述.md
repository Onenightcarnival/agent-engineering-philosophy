# 第八章：不要复制人类组织病

最后回到一个更贴近 agent 工程的问题：一群 agent 一起工作时，哪些人类组织经验可以学，哪些不能碰。

人力资源是这本书的主干隐喻，但不能整套照搬。人类组织是在一组旧条件下长出来的：人脑窗口有限，角色切换困难，信息传递慢，很多岗位和流程因此出现。agent 改掉了其中一部分条件。它能处理更大的上下文，能临时生成隔离的判断岗位，也更容易成为通才。旧组织里的层级、流程和岗位，都要先过一遍审计。

人类组织里有些机制来自分工本身：岗位边界、交接契约、授权路径。这些要保留。也有些机制来自人性失败：抢功、甩锅、表演、层级压制事实。这些不能复制。agent 还会长出自己的新病：迎合、互相背书、上下文污染、把流畅当正确。使用 agent 的人也会产生幻觉，把流畅当确认，把同源重复当共识。这些都要另设机制。

多 agent 工程不做公司仿真，它要重新设计一种团队。这一章收束在这条判断上。
