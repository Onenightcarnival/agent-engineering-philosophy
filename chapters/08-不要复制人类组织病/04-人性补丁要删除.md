# 人性补丁要删除

人类组织里还有另一类机制，用来防人。

防抢功，防甩锅，防摸鱼，防站队，防表演，防上级不懂装懂还硬要拍板。这些机制未必没有价值。很多时候正是它们让人类组织还能勉强运转。但它们的价值来自一个前提：人有自己的利益、面子、恐惧和权力欲。

这个前提不能直接搬给 agent。

## 不要把表演当绩效

很多人类绩效制度，是在信息不完整的条件下评估人。看汇报，看态度，看谁在会上讲得清楚，看谁更会包装自己的贡献。它们不全是坏制度，但确实混进了大量表演。

agent 团队不需要复制这套东西。它的每一步工具调用、中间产物、返工路径、最终结果都可以留痕。工作记录已经能检查，就不要再发明一套让 agent “讲述自己多努力”的仪式。

绩效应该来自 trace、产物和 eval，不来自汇报话术。这条线在第六章已经讲过，到了团队层更重要。多 agent 系统越复杂，越要看真实工作记录，少看自我描述。

## 不要把审批当责任

人类组织里常见层层审批。它一部分是协调机制，一部分是责任焦虑：多几个人签字，出了事看起来就不只算一个人的事。

agent 团队不能学这个坏习惯。让多个 agent 都点过头，不等于责任已经处理好。几个 agent 互相确认，也不等于事实更可靠。审批如果只是把责任摊薄，它就是人性补丁。

有用的是授权边界和最终担责点：什么动作可以自动做，什么动作必须上报，谁有最终否决权。审批链条如果不能改变风险，只是在制造“大家都看过”的心理安慰，就该删。

## 不要让层级压过事实

人类组织最难删的一种病，是位置冒充判断力。

懂的人没有裁决权，有裁决权的人不懂。事实判断碰到层级，事实让路。AI 进来以后，这件事不会自动消失。如果把 agent 团队设计成一套僵硬层级，上级 agent 永远压过下级 agent，那只是把旧病换了个外壳。

agent 团队应该让事实判断流向最接近事实的岗位。刚跑完 trace、见过错误、掌握上下文的 agent，可能比名义上的上级更懂那个局部。最终是否接受它的判断，是责任问题；但不能因为层级否认它在局部事实上的优势。

人性补丁要删除，不是 agent 更高尚，而是很多补丁针对的病因已经换了。旧病不该照搬，新病要另治。
