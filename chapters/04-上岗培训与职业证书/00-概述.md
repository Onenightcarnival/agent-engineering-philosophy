# 第四章：上岗培训与职业证书

岗位定了，人选了，接下来是上岗。一个 agent 怎么获得这个岗位需要的具体能力？

靠 skill。但 skill 很容易被看成"又一个工具"，这一章要把它从工具堆里拆出来。skill 是能力单元，有两副面孔：朝内，它是上岗培训，让 agent 胜任某个具体岗位；朝外，它是职业证书，可以跨 agent、跨环境、跨岗位复用和验证。一个 skill 要留下来，不能只是一段碰巧能跑的脚本，它得可复现。

第一章里"skill 像简历的一条"那点火光，在这一章落成正式的定义。
