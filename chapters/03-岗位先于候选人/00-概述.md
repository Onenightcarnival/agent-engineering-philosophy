# 第三章：岗位先于候选人

上一章把候选人交到了门口：有资历，没岗位。这一章讲招聘与入职，核心是一个被普遍颠倒的顺序——先定义岗位，再选候选人。

系统提示词在这里不是要反复念叨的咒语，是一份岗位合同：写清职责、权限、边界、汇报路径。自主性不来自放任，来自清楚的边界。而大多数 agent 跑不好，真因不在模型弱，在岗位没定义清——这是这本书反复要回到的一条判断。
