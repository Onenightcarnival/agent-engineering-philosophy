# 第三章：岗位先于候选人

上一章把候选人交到了门口：有学历，没岗位。这一章讲招聘与入职，核心是一个被普遍颠倒的顺序——先定义岗位，再选候选人。

系统提示词在这里不是要反复念叨的咒语，是一份岗位合同：写清职责、权限、边界、汇报路径。自主性不来自放任，来自清楚的边界。大多数 agent 跑不好，真因不是模型弱，而是岗位没定义清——这是全书反复要回到的一条判断。

把 agent 当打工人看，也意味着用人方不能只问“它能为我做什么”。更该先问：我给它的岗位清不清楚，工具够不够，权限边界明不明确，出了问题有没有反馈。很多 agent 不是不肯干活，而是被扔进了一份没人写清的工作里。
