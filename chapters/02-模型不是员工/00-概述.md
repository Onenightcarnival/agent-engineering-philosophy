# 第二章：模型不是员工

图齐了之后，可以拿这张图从头走一遍 agent 的一生。

一生的起点不在 agent 身上，在它出生以前。这一章讲的就是"出生以前"：模型训练公司交付的不是 agent，是候选人。预训练是通识教育，后训练是职业教育，模型分级是一纸学历。学历说明候选人的水平，不说明它适合哪份工作。

把模型直接当员工使唤，是最早、也最容易犯的错位。它混淆了两件事：一个人有能力，和一个人在岗位上能干活。
