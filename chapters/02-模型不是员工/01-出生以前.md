# agent 出生以前

把 agent 当一个人来看，会自然问出一个问题：这个人是从哪里来的？

答案是，他来的地方比你想象得早。模型训练公司——OpenAI、Anthropic、那一长串名字——交付出来的，不是一个 agent，是一个候选人。一个受过完整教育、有能力、有资历，但还没有岗位、没有职责、没有工作环境的人。把这样一个人直接拉来当员工，等于刚在招聘网站上看到一份简历，就默认这个人已经在为你干活。

## 候选人不是员工

"用了最强的模型，agent 就该很强"，这个期待错在哪，从人的角度一眼能看出来。招进一个名校博士，公司不会因此自动运转。还得给他岗位、职责、权限、工具，告诉他向谁汇报、什么算干完。能力是他自带的，岗位是公司给的。两样缺一样，这个人就闲在那里，或者乱来。

模型就是那个博士。它在被训练出来的那一刻，已经具备了相当的通用能力，但它对"要在哪个岗位上、为谁、做什么"一无所知。这些不写在模型里，写在它出生之后你为它准备的那一切里。

## 模型能力不是 agent 能力

于是有了这一章要钉死的第一个区分：模型能力，不等于 agent 能力。

模型能力是候选人的素质，由训练决定，你买来即得。agent 能力是这个候选人在你给的岗位、工具、环境里实际交付的东西，由你的工程决定。前者是上限，后者是实绩，中间隔着招聘、入职、上岗、安家这一整段——也就是后面几章的内容。

选模型，只是招聘里的一步，不是招聘的全部，更不是 agent 工程的全部。一个 agent 跑得好不好，多数时候不取决于你买的候选人有多强，取决于他出生以后，你把这一段做得有多清楚。
