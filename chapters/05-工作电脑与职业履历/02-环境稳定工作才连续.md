# 环境稳定，工作才连续

工作电脑上有什么？文件、依赖、配置、缓存、做到一半的项目。这些加在一起，构成 agent 的工作环境——它接着往下干活时所站的地方。

工作环境要起作用，第一要求是稳定：今天调好的，明天还在；这一轮的产物，下一轮找得到。环境一旦每次都要重建，就等于员工每天上班先花半天重新布置工位，干活的时间所剩无几，连续性也就无从谈起。

## 稳定不等于放任堆积

稳定是说环境可靠地延续，不是说什么都往里堆、堆了就不管。

一个长期使用的工作环境会自然积累东西，其中有该留的——稳定的依赖、整理好的项目、复用的配置；也有该清的——过期的缓存、一次性的临时文件、试错留下的垃圾。把工作环境当 agent 的一部分来设计，就要给它做版本化和维护，像对待一台长期使用的机器，而不是一个随手搭起、放任其乱的临时空间。环境状态能重建，也能回到某个已知的好版本，稳定才不是脆弱的偶然。

## 工作电脑也是一道边界

沙箱还有第二重身份，和第三章接得上：它在给 agent 一个工作环境的同时，也是一道隔离边界。

agent 能动的，就是这台机器上、这个沙箱里的东西；够不到的，就是它越不出去的地方。这让"工作电脑"和"权限边界"成了同一件事的两面——它既是 agent 安家干活的地方，也是它能碰到哪里为止的物理围栏。配工作环境时，顺手就把这道围栏画了：该能碰的留在沙箱内，不该碰的隔在沙箱外。环境的连续性和边界的清晰，在这里一起设计。
