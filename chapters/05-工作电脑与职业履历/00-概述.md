# 第五章：工作电脑与职业履历

岗位有了，学历配了，能力上了。还差一样东西，才能让 agent 从"一次性对话"变成"长期工作的人"：连续性。

连续性有两个载体。一个是工作环境——带持久化卷的沙箱，相当于一台属于这个 agent 的工作电脑，文件、依赖、半成品都留在上面。另一个是记录——长期记忆，相当于职业履历，做过什么、踩过什么坑、服务过谁，都记在案。这一章讲这两样，最后说清一件事：履历不是摆设，它会改变 agent 的判断。

到这一章为止，一个 agent 作为个体的前半生——出生、入职、上岗、安家——就讲完了。
