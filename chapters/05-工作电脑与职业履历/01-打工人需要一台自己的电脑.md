# 打工人需要一台自己的电脑

设想一个员工，每天上班前硬盘被清空。昨天装好的工具没了，昨天写到一半的文档找不到了，昨天调通的环境要重搭一遍。他再能干，也只能做当天就能从头干完的活。

没有持久化环境的 agent，就是这个员工。一问一答跑完，状态归零，下一轮从空白开始。它能应付一次性的小任务，扛不起需要跨越多轮、多天的工作。

## 持久化沙箱就是工作电脑

带持久化卷的沙箱，是给 agent 配的一台工作电脑。

它的关键不在"能跑代码"，在"东西留得下"。这一轮装的依赖，下一轮还在；今天生成的中间文件，明天还能接着用；调好的配置不会随对话结束而蒸发。有了这台不被清空的机器，agent 才能从"无状态的一问一答"，进入"有连续工作面的长期任务"。

这不是高级功能，是一类任务的入场券。凡是要跨会话、跨多天、需要在前一步成果上继续往下做的活，都需要一个不会归零的工作面。指望一个每天清空硬盘的人去做需要一周的项目，是任务和环境的错配。

## 工作面是 agent 的一部分

由此引出这一章的基本态度：工作环境不是 agent 之外的临时脚手架，是 agent 这个角色的一部分。

一个人的工作状态，不只在他脑子里，也在他的电脑里——摊开的文件、装好的软件、整理过的目录。agent 同理。把它的环境当成"用完就拆"的临时设施，还是当成"跟着这个岗位长期存在"的工作面，决定了它能不能连续工作。下一篇讲这个工作面上有什么，以及为什么"稳定"是它的第一要求。
