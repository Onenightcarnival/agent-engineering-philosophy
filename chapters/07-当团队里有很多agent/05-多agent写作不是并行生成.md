# 多 agent 写作不是并行生成

写作最容易暴露多 agent 的误用。

常见做法是把题目丢给几个 agent：一个写引言，一个写论证，一个写案例，一个写结论。它们各自生成一段，再把段落拼起来。表面上分工明确，结果通常很差。这只是并行生成，还不是写作团队。

文章不是段落的集合。文章有中心判断，有内部节奏，有取舍，有些话该说，有些话不该说。把这些东西拆散，再指望最后自动合起来，得到的多半是一篇每段都通顺、整体却没有判断的稿子。

## 写作岗位不是章节分配

多 agent 写作要拆判断岗位，不要按章节分包。

立意 agent 判断这篇文章到底要说什么。它不急着写漂亮句子，只负责把核心论点钉住。

结构 agent 安排论证顺序。它关心先说什么、后说什么，哪里需要铺垫，哪里该直接下判断。

批判 agent 找漏洞。它不负责让文章更圆滑，只指出偷换概念、论据不足、跑题和自我重复。

素材 agent 补材料。它不替文章决定方向，只补足论证需要的事实、例子和反例。

风格 agent 统一语气。它不能改掉观点的锋利，只能让表达更干净，更像同一个人写的。

这些岗位按写作里的判断功能切。一个 agent 写一段，只是在分配体力；一个 agent 负责一种判断，才是在组建写作团队。

## 好文章需要收束，不需要平均

多 agent 写作最危险的地方，是每个 agent 都有一点道理。最后如果把每一点都保留下来，文章就会变成观点展览。

写作不是公平分配版面。批判 agent 找出的漏洞，不一定都要补进正文；素材 agent 找到的例子，不一定都值得留下；风格 agent 提出的圆润表达，也可能削掉文章的判断力。多 agent 写作需要一个最终取舍点。没有这个点，所有岗位都会把自己的局部正确推向全文，文章就散了。
