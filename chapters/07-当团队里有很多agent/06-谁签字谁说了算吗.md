# 谁签字，谁说了算吗

上一章说，agent 组织可以删掉一部分人性补丁。但有一种病删不掉，甚至会被 AI 放大：权力压过判断。

很多组织不是没人干活，也不是没人懂，而是懂的人没有裁决权，有裁决权的人不懂。外行指导内行，内行负责擦屁股。AI 进来以后，这个问题不会自动消失。权力型组织会把 AI 当成更听话的下属，而不是更接近事实的同事。它会让 agent 写报告、做分析、跑流程，但只要结论碰到权力结构，事实仍然要给位置让路。

所以 AI 救不了权力型组织。它能降低协作成本，能留下工作记录，能让很多事变得可观测；但它不能替一个组织尊重事实。一个组织如果本来就把身份、辈分、层级放在判断前面，AI 只会让这套东西跑得更快。

## 干活的人最接近真实

"干活的才是领导"这句话有一种粗粝的对。它不是说所有管理都该取消，也不是说谁敲键盘最多谁就该发号施令。它说的是另一件事：真正接触工作的人，通常最接近真实。

工程里最知道该怎么改的，往往是长期维护这块代码的人。客服里最知道客户为什么生气的，往往是一线处理工单的人。一个 agent 团队里，最知道某个子任务风险在哪里的，往往是刚刚跑完 trace、踩过错误、看过上下文的那个 agent。

工作会产生一种判断力。不是抽象的聪明，而是贴着对象长出来的判断力：知道哪里会坏，知道哪个约束不能碰，知道表面上顺的方案为什么其实危险。这种判断力不是职位给的，是工作给的。

外行指导内行，荒唐就在这里。外行当然可以提出目标，可以决定资源，可以表达风险偏好；但当他开始裁决具体事实，问题就变了。他不再是在管理工作，而是在用位置替代判断。组织里很多低级事故，都是从这一刻开始的。

## 权力不能冒充判断力

人类很难接受自己在局部不如别人。尤其当那个"别人"在名义上低自己一级时，这件事更难接受。

父亲和儿子争论，理亏时拿辈分压人；领导和专家争论，说不过时拿层级压人；人和 agent 争论，发现 agent 判断更准时，转而说"你只是工具"。身份权威在事实权威面前输了，就把规则换成身份。

这不是小脾气，是组织设计里的大问题。一个组织如果允许权力在事实争论里强行获胜，就会奖励无知的自信，惩罚诚实的专业。久而久之，懂的人学会闭嘴，不懂的人学会拍板。看起来层级清楚，实际是在系统性地驱逐判断力。

agent 会把这个问题照得更亮。很多局部任务上，agent 确实可能比人判断得更准。它更快地搜索，更稳定地比较，更少被面子和身份牵着走。一个实事求是的人，应该愿意在这些局部接受 agent 的指导。谁在这件事上判断更准，谁就该指导这件事。

这句话听起来刺耳，是因为人把"被指导"和"被支配"混在了一起。接受 agent 在某个局部指导我，不等于把自己交给 agent。它只是承认一件事：判断力是局部的，不是随身份整体发放的。

## 谁担责，谁有最终否决权

但事情不能停在"谁更懂谁说了算"。还有另一条线：后果。

有些时候，签字的人确实应该拥有最终否决权。不是因为他一定更懂，而是因为后果落在他身上。父亲替儿子承担后果时，可以说"这件事我担着，所以最后由我决定"；公司负责人要对外签合同、承担赔偿、抵押信用时，也必须保留最后一道闸。

这不是封建残余，是责任结构。不能让一个不承担后果的人，替承担后果的人做不可逆决定。前面讲授权与升级路径时，说不可逆、高风险、超出岗位边界的事要向上交，原因就在这里：越接近不可逆，越要回到能担责的地方。

矛盾也在这里。谁签字谁说了算，看起来合理；但如果签字的人没有判断力，为什么他会坐在签字的位置上？

这个问题没有漂亮解法。现实世界里，法律人格、资本、职位、家庭责任，经常先于判断力存在。一个人可能因为制度安排坐在签字位上，却并不最懂那件事。工程上能做的，是把两种权力拆开。

签字的人有最终否决权，但不自动拥有事实裁判权。

他可以说："这个风险我不接受。"他不该说："因为我签字，所以你的专业判断是错的。"前者是在承担后果，后者是在冒充懂行。健康的 agentic 组织，应该让事实判断流向最懂的人或 agent，让最终否决留在能担责的人那里。两者重合最好，不重合时，至少不要互相冒充。

## AI 救不了权力型组织

AI 救不了权力型组织，因为权力型组织的问题不在能力不足，而在权力不受事实约束。它缺的不是更快的分析、更勤奋的执行、更漂亮的总结，而是承认判断力来自工作、来自证据、来自可追溯的结果，不来自位置本身。

agentic 组织值得期待的地方，不是让老板拥有一群不会反驳的虚拟员工，而是让事实更难被身份压住。trace 会留下谁做了什么，eval 会暴露谁稳定可靠，工作记录会把"我觉得"逼回"你证明"。这些东西不能自动带来公正，但它们会让权力型组织更难假装自己正确。

"干活的才是领导"落到 agent 工程里，就是这三句话：谁最接近真实，谁主导判断；谁承担后果，谁保留最终否决；谁既不懂也不担责，却要指挥内行和 agent，那不是领导，是组织噪声。

下一章谈组织会怎么变。变的第一件事，也许不是公司突然消失，而是很多过去靠身份维持的指挥关系，开始失去技术上的借口。
