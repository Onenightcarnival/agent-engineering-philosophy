# 保留协调机制，删掉人性补丁

人力资源是这本书的主干隐喻，到团队这一层尤其管用——人类组织积累了几十年管理协作的经验，现成可借。但借的时候不能整套照抄。

因为人类组织的机制其实是两类东西混在一起的。一类是协调机制，另一类是为了压住人性弱点打上的补丁。两类的命运不一样。

## 两类机制

协调机制，解决的是"多个角色怎么配合"这个永恒问题，和人性无关：岗位划分、交接约定、授权层级、升级路径。这些机制就算把人换成完全理性、没有私心的角色，照样需要——因为分工本身就要求协调。这一类要保留，前面几章其实已经在用。

人性补丁，是为人的弱点设的额外防线：背调，因为人会在简历上造假；层层签字的审批，因为出了事要找得到担责的人、也因为有人会滥用权限；繁复的绩效考核仪式，因为有办公室政治、有表演和站队。这些机制本身不创造价值，它们是抗体，是组织为了对付人性之恶不得不付出的成本。

## agent 让一部分补丁可以删掉

agent 没有人性的那些弱点：它没有 ego，不怕被下属盖过；它的动作可观测，藏不住质量也赖不掉责任。上一篇说可观测性抽掉了信息不对称这层土壤——土壤没了，长在土壤上的那些补丁也就失去了存在的理由。

于是 agent 组织有机会比人类组织精简：那些纯粹为对付人性而设的补丁，可以删。但要划清边界——这种精简只在"AI 确实消除了底层信息不对称"的那些轴上成立，不是无差别地删。哪些能删，要带判断，不能一刀切。

## 还要留意 agent 长出的新病

而且，删掉旧补丁，不等于从此无病。

agent 会长出自己的新毛病，需要新的补丁。最突出的就是上一篇点到的迎合倾向——它倾向于讨提问者欢心，而不是坚持说对的。这是人类组织里没有完全对应物的新病，对付它可能要新增机制，而不是照搬哪条人类经验。

所以移植组织机制的准则是带判断力的三件事：协调机制保留，人性补丁删掉，agent 的新病新治。把人类 HR 当现成答案整套搬过来，会抄进一堆 agent 根本不需要的补丁；把它一概当过时的东西全盘抛弃，又会丢掉协调这门真功夫。分清楚，才用得好这个主干隐喻。
