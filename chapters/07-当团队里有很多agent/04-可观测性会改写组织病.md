# 可观测性会改写组织病

人类组织有几种顽疾，几乎每家公司都见得到：抢功（把别人的成果摘到自己名下）、甩锅（把责任推到别人头上）、劣币驱逐良币（干得好的留不住，混得好的上得去）。

直觉把这些归为人性之恶。这话不假——很多信息不对称，正是有人为了自己的利益刻意制造、刻意维持的。但把账只记在人性上，开不出工程药方：如果根全在人性，那就无解，剩下的只有劝人向善。所以这里先把人性搁在一边，单看机制——会发现它们都站在同一块地基上：信息不对称下的均衡。

## 这些病靠信息不对称活着

把每一种病拆开看，背后都站着一种信息不对称。

抢功能得逞，是因为归因有噪声。谁真正出了力，事后说不清、查不准，功劳又稀缺，于是嗓门大、离领导近的人摘了果子。劣币驱逐良币，是阿克洛夫的柠檬市场——当质量不可观测，买方只肯出平均价，高质量的卖家被挤走，劣币留下。甩锅成立，是因为责任链条糊，出了事找不到唯一的源头，谁会甩谁就脱身。

共同的机制是：这些病不是靠"坏人"维持的，是靠"看不清"维持的。信息不对称是它们的生存土壤。

## agent 团队抽掉了那层土壤

agent 团队有一个不同的底层条件：每个动作都留痕。

上一章说绩效来自工作记录，把它推到团队，就是一种接近完美的归因——谁在哪一步做了什么，trace 里清清楚楚，像一份不会撒谎的 git blame。归因从昂贵、嘈杂，变得便宜、精确，抢功就失去了土壤。质量从藏得住变成藏不住，eval 和轨迹可被检验，劣币驱逐良币也被部分打掉。责任链条从糊变清，甩锅难了。

关键在于，这不是因为 agent 更高尚。agent 没有道德上的优越，它只是消除了那些病赖以生存的信息不对称。病灶的土壤被抽掉，病就长不起来——这是一个结构性的结果，不是一次道德的胜利。

## 但可观测性不是万能药

要诚实地补一句：可观测性消除的，是"信息不对称型"的病，不是所有问题。

有些麻烦不靠看不清活着，抽掉信息不对称也不会消失。更要紧的是，agent 还带着另一种倾向——它被训练得倾向于迎合、让提问者满意，而不是无条件求真。这类倾向不属于信息不对称，可观测性治不了它，得靠另外的机制来对付。这是一条更黑、也更难的线，本书后面会回到。

但仅就信息不对称这一类病而言，结论是清楚的：把可观测性当成组织设计的杠杆，而不只是排错工具。它是从结构上消除一类组织病的手段——这正是把人类组织机制移植到 agent 时，第一件该想清的事。下一篇接着说：哪些机制该抄，哪些该删。
